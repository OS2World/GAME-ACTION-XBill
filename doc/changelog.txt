xBill 2.1 - ArcaOS SDL2 Port - Changelog
=========================================

Port target: ArcaOS 5.x (OS/2)
Toolchain:   GCC/EMX + OpenWatcom linker (wlink/wl.exe via EMXOMFLD)
SDL version: SDL2 + SDL2_image


--- Initial Port ---

  * Created src/sdl2.c: full SDL2 UI backend implementing all UI_methods
    function pointers (set_cursor, load_cursor, load_picture, set_icon,
    picture_width, picture_height, graphics_init, clear_window,
    refresh_window, draw_image, draw_line, draw_string, start_timer,
    stop_timer, timer_active, popup_dialog, main_loop, initialize,
    make_main_window, create_dialogs, set_pausebutton, update_dialog).

  * Created src/sdl2.h: header declaring sdl2_setmethods().

  * Created src/config.h: defines USE_SDL2=1; leaves USE_ATHENA,
    USE_MOTIF, USE_GTK undefined to avoid spurious #ifdef matches in UI.c.

  * Patched src/UI.c: added #if USE_SDL2 guard and sdl2 entry in guis[].

  * Patched src/Game.c: added #ifndef SCREENSIZE guard so the -DSCREENSIZE
    flag on the compiler command line overrides the in-source default.

  * Created makefile.gcc: GNU make build file for GCC/EMX on ArcaOS.
    Uses -Zomf -Zhigh-mem -Zmap, links via OpenWatcom linker.

  * Created compile.cmd: OS/2 build script; sets EMXOMFLD_TYPE=WLINK,
    EMXOMFLD_LINKER=wl.exe, EMXOMFLD_PRELINK=0; logs all output to
    compile.cmd.log; checks for bin\xbill.exe to confirm success.

  * Created src/xbill.def: OS/2 module definition (WINDOWAPI, STACKSIZE,
    HEAPSIZE).


--- Graphics and Image Loading ---

  * All XPM pixmaps (sprites, logo, icon, OS icons, computer images, etc.)
    are included as static C arrays via #include and loaded with
    IMG_ReadXPMFromArray() from SDL2_image.

  * All XBM cursor bitmaps (hand_up, hand_down, 10 OS cursors) are included
    as static C arrays. XBM uses LSB-first bit order within each byte;
    implemented pixel-by-pixel iteration rather than byte reversal to
    correctly parse each bit position.

  * Added palmcpu.xpm to both the #include list and xpm_table[] after it
    was found missing at runtime.


--- Cursor System ---

  * Initial attempt used SDL_CreateColorCursor() from XBM data; abandoned
    because SDL2's OS/2 PM backend does not render color cursors correctly.

  * Switched to full software cursor rendering:
    - SDL_ShowCursor(SDL_DISABLE) hides the SDL/PM cursor entirely.
    - xbm_to_texture() converts XBM data (LSB-first) to an ARGB SDL_Texture
      with per-pixel transparency.
    - OS cursors (apple, bsd, hurd, linux, next, os2, palm, redhat, sgi,
      sun) use XPM color data loaded via IMG_ReadXPMFromArray().
    - sdl2_refresh_window() draws the cursor texture at the tracked mouse
      position (gMouseX, gMouseY) at 2x scale, scaled consistently with
      the game area.
    - Mouse motion events update gMouseX/gMouseY and trigger a refresh
      without touching the game render texture.


--- Render-to-Texture Architecture ---

  * Introduced gGameTex (SDL_TEXTUREACCESS_TARGET): game draws into this
    texture; sdl2_refresh_window() composites it scaled 2x onto the screen
    and then draws the software cursor and menu bar on top.

  * This eliminates cursor ghost trails: moving the cursor does not modify
    the game texture, so refreshes are always clean.

  * set_game_vp() / clear_vp() helpers switch the render target between
    the game texture and the screen.


--- Menu System ---

  * Replaced SDL_ShowMessageBox-based menus with custom SDL2-drawn dropdown
    menus rendered directly via the SDL renderer.

  * Menu bar (22 px tall) renders "Game" and "Info" labels at 2x font scale.

  * Dropdown panels drawn on click with hover highlight (dark blue),
    separator lines, and drop shadow. Panel width 280 px, item height 22 px,
    item text at 2x font scale.

  * Menu loop composites gGameTex on each frame so the game area is visible
    behind the open dropdown (fixes garbage/gray background bug).

  * Render target restored to gGameTex after menu closes via set_game_vp().


--- Font Rendering ---

  * Embedded CP437 8x8 bitmap font (font8x8[]) used for all text.

  * blit_char() / blit_str(): render at 1x scale (game status bar).

  * blit_char_s() / blit_str_s(): render at arbitrary pixel scale; used at
    2x for menu bar labels and dropdown item text.


--- Dialog System ---

  * Blocking dialogs (New Game, Quit, Pause, High Scores, Story, Rules,
    About, Enter Name, End Game) use SDL_ShowSimpleMessageBox or
    SDL_ShowMessageBox (native PM dialogs).

  * DIALOG_SCORE (between-level score) replaced with sdl2_score_popup():
    a non-blocking overlay rendered by the SDL renderer that shows the
    level score and auto-dismisses after 2 seconds. Clicking or pressing
    any key also dismisses it early.


--- Timer ---

  * SDL_AddTimer one-shot callback pushes a registered user event
    (gTimerEvent). Main loop handles it by calling Game_update() and
    re-arming the timer, mirroring the X11 interval-timer behavior.

  * Stale timer events are flushed before and after blocking dialogs to
    prevent accumulated ticks from running the game while the dialog is open.


--- Window and Scaling ---

  * Game logical size: SCREENSIZE=375 (passed via -DSCREENSIZE=375).
    Displayed at 2x scale: 750x750 game area on screen.

  * Window size: 750 x 772 (game area width x game area height + menu bar).
    No gray strip; window matches game area exactly.

  * Window positioned at screen center using SDL_GetDisplayBounds() to
    compute explicit coordinates (more reliable than SDL_WINDOWPOS_CENTERED
    on the OS/2 PM SDL2 backend).


--- Keyboard Shortcuts ---

  * Ctrl+X: immediate quit (Game_quit(), no confirmation dialog).
  * Escape: quit with confirmation dialog.
  * N: new game.
  * P: pause/resume.
  * W: warp to level.
  * H: view high scores.


--- Error Handling ---

  * sdl2_initialize() redirects stderr to xbill_err.log via freopen(),
    capturing all fatal() messages. WINDOWAPI executables on OS/2 have no
    visible console, so errors would otherwise be invisible.


--- Compiler Warnings Fixed ---

  * Added -Wno-unused-function, -Wno-restrict, -Wno-format-overflow,
    -Wno-builtin-declaration-mismatch to CFLAGS for third-party source files.

  * Added #include <strings.h> to src/Game.c (strncasecmp) and
    src/UI.c (strcasecmp) to resolve implicit-declaration warnings.
    Note: src/UI.c also includes the local "strings.h" (dialog text);
    the system <strings.h> is a separate header with a different guard.

  * Removed -DUSE_GTK=0 (and similar) from CFLAGS: UI.c uses #ifdef
    (existence) guards, not #if (value) guards, so defining to 0 would
    incorrectly enable the GTK code path without its headers. Unused
    backends are left undefined entirely.
